## 命名规范

`S<阶段>-T<两位序号>-<英文主题>.md`，例如 `S1-T03-video-windows.md`。

每份文件只覆盖一次会话可完成、可独立验证的实现单元。状态使用 `TODO`、`DOING`、`DONE`、`BLOCKED`；完成后填写完成记录。
